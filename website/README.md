# Global Travel Hub

A premium, modern travel platform and AI trip planner specializing in Kerala tour packages, hotel bookings, transport services, and global travel tickets.

## Features

- 🌴 **Curated Kerala Tour Packages**: Explore Munnar, Alappuzha backwaters, Fort Kochi, Wayanad, and Varkala cliffs.
- 🤖 **Nila AI Trip Planner**: Interactive AI travel planning tool that creates custom itineraries and updates live interactive maps.
- 🏨 **Hotels & Homestays**: Handpicked accommodations across Kerala and global destinations.
- 🚗 **Transport & Tickets**: Bus, train, flight bookings, taxi rentals, and visa assistance.
- 📱 **Saved Trips**: Trips automatically saved in browser local storage for seamless access.

## Technologies Used

- **Vite & React 18**
- **TypeScript**
- **Tailwind CSS & Framer Motion**
- **shadcn/ui & Lucide Icons**
- **Leaflet & OpenStreetMap** (Interactive Map Integration)

## Getting Started

```sh
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```
